# Introduction to AI & Python

## Artificial Intelligence

Artificial Intelligence (AI) is a technology that enables machines to perform tasks that normally require human intelligence.

Examples:
- Chatbots
- Voice assistants
- Recommendation systems
- Image recognition

## Machine Learning

Machine Learning (ML) is a part of AI that allows computers to learn from data and make predictions or decisions.

Examples:
- Spam detection
- Recommendation systems
- Prediction systems

## Deep Learning

Deep Learning is a part of Machine Learning that uses neural networks with multiple layers.

Examples:
- Face recognition
- Speech recognition
- Image classification

## AI vs ML vs Deep Learning

AI is the broad concept.

ML is a subset of AI.

Deep Learning is a subset of ML.

AI → ML → Deep Learning

## Real-World Applications of AI

- Healthcare
- Banking
- Education
- Transportation
- E-commerce
- Cybersecurity
- Entertainment
